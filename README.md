# SmartSnow

**SmartSnow** — учебный исследовательский проект на языке Python, посвящённый математическому моделированию и поиску оптимального расположения снежных пушек вдоль лыжной трассы.

Проект разрабатывается на примере лыжной трассы в районе посёлка Корта (Республика Марий Эл).

## 1. Цель проекта

Разработать программу, которая позволит определять оптимальное количество снежных пушек и места их установки для обеспечения необходимого покрытия лыжной трассы искусственным снегом.

При моделировании предполагается учитывать:

- геометрию и ширину лыжной трассы;
- рельеф местности;
- дальность действия снежных пушек;
- направление и сектор распыления снега;
- допустимые места установки оборудования;
- эффективность покрытия трассы.

Основная задача проекта — разработка математической модели и алгоритма оптимизации размещения снежных пушек.

## 2. Текущие возможности

На данном этапе реализованы:

- загрузка координат лыжной трассы из JSON-файла;
- получение высот точек по цифровой модели рельефа;
- преобразование географических координат в метрические и обратно;
- создание объектов `Point`, содержащих координаты и высоту;
- формирование объекта `Track` с параметрами лыжной трассы;
- централизованная настройка приложения.

**В разработке:**

- математическая модель снежной пушки;
- расчёт зоны распыления искусственного снега;
- определение допустимых мест установки;
- алгоритм оптимального размещения пушек;
- оценка покрытия лыжной трассы;
- визуализация результатов на карте.

## 3. Используемые технологии

Проект разрабатывается на языке **Python 3.12**.

Для решения вспомогательных задач используются готовые сторонние библиотеки.

### Сторонние библиотеки

| Библиотека | Назначение |
|---|---|
| [bmi-topography](https://github.com/csdms/bmi-topography) | Получение цифровой модели рельефа через сервис OpenTopography. Поддерживает набор данных Copernicus GLO-30. |
| [rasterio](https://rasterio.readthedocs.io/) | Чтение географических растров GeoTIFF и определение высот точек по цифровой модели рельефа. |
| [pyproj](https://pyproj4.github.io/pyproj/) | Преобразование географических координат в метрические и обратно. |
| [python-dotenv](https://github.com/theskumar/python-dotenv) | Загрузка параметров конфигурации и API-ключей из файла `.env`. |

В первоначальной версии получения высот также использовалась библиотека [requests](https://requests.readthedocs.io/) для HTTP-запросов. В текущей реализации загрузка рельефа выполняется через `bmi-topography`.

Сторонние библиотеки позволяют не разрабатывать собственные механизмы получения географических данных и сосредоточиться на математической модели SmartSnow.

### Источник данных о высотах

Для получения высот используется цифровая модель поверхности **Copernicus GLO-30** с пространственным разрешением около 30 метров.

Данные предоставляются через сервис [OpenTopography](https://opentopography.org/).

Модель загружается для прямоугольной области, охватывающей лыжную трассу, с дополнительным запасом территории.

Следует учитывать, что Copernicus GLO-30 является цифровой моделью поверхности: на участках с растительностью высоты могут отражать не только поверхность земли, но и расположенные над ней объекты.

### Системы координат

SmartSnow использует две системы координат:

- **WGS84 (EPSG:4326)** — географические координаты в градусах: широта и долгота.
- **UTM, зона 38N (EPSG:32638)** — плоские координаты `X` и `Y` в метрах, подходящие для района исследуемой трассы.

Географические координаты используются для хранения исходных данных и отображения на карте.

Метрические координаты используются для расчёта расстояний и геометрического моделирования.

## 6. Настройка приложения

### 6.1. API-ключ OpenTopography

Для загрузки цифровой модели рельефа необходим API-ключ OpenTopography.

Получить его можно на сайте:

https://opentopography.org/

Создайте файл `.env` в корневом каталоге проекта или скопируйте `.env.example`:

Linux / macOS:

```bash
cp .env.example .env
```

Windows (PowerShell):

```powershell
Copy-Item .env.example .env
```

Содержимое `.env`:

```dotenv
APP_DEBUG=true
OPENTOPOGRAPHY_API_KEY=your_api_key_here
```

Замените `your_api_key_here` своим ключом.

**Важно:** файл `.env` содержит конфиденциальные настройки и не должен попадать в Git-репозиторий.

### 6.2. Настройки получения высот

В `config/app.py` находятся общие настройки приложения.

Пример конфигурации:

```python
"elevation": {
    "api_key": os.getenv("OPENTOPOGRAPHY_API_KEY"),
    "dataset": "COP30",
    "buffer_meters": 200,
},
```

Параметры:

- `api_key` — ключ доступа к OpenTopography;
- `dataset` — используемая цифровая модель рельефа;
- `buffer_meters` — запас территории вокруг прямоугольных границ трассы в метрах.

Запас 200 метров используется только при загрузке рельефа и не определяет допустимое расстояние установки снежных пушек.

## 7. Исходные данные

Географические координаты лыжной трассы хранятся в файле `data/track.json`.

Пример:

```json
{
  "points": [
    {
      "latitude": 56.600491,
      "longitude": 47.966353
    },
    {
      "latitude": 56.600701,
      "longitude": 47.965990
    },
    {
      "latitude": 56.600894,
      "longitude": 47.965680
    }
  ]
}
```

Каждая точка содержит:

- `latitude` — широту в градусах;
- `longitude` — долготу в градусах.

Точки должны быть записаны последовательно вдоль маршрута.

В текущем примере используется замкнутый маршрут из 127 точек, подготовленный по географическим данным трассы в Корте.

### Параметры трассы

В `config/local.py` задаются параметры локального запуска:

```python
PARAMS = {
    "track": {
        "points": points,
        "width": 6.0,
        "installation_buffer": 2.0,
        "allow_on_track": True,
    },
}
```

Значение параметров:

| Параметр | Описание |
|---|---|
| `points` | Список географических координат трассы. |
| `width` | Ширина лыжной трассы в метрах. |
| `installation_buffer` | Отступ от трассы для размещения оборудования в метрах. |
| `allow_on_track` | Разрешена ли установка оборудования непосредственно на трассе. |

## 8. Запуск программы

После установки зависимостей и настройки `.env` выполните команду из корневого каталога проекта:

```bash
python main.py
```

В Linux можно запустить программу непосредственно через интерпретатор виртуального окружения:

```bash
.venv/bin/python main.py
```

### Что происходит при запуске

1. Загружаются общие настройки приложения.
2. Из `data/track.json` считываются координаты трассы.
3. Создаётся объект `App`.
4. Приложение создаёт объект `Track`.
5. `ElevationProvider` получает высоты точек.
6. `CoordinateConverter` переводит географические координаты в метры.
7. Создаются объекты `Point(x, y, elevation)`.
8. Программа выводит информацию о подготовленной трассе.

### Пример результата

```text
Ширина трассы: 6.0
Буфер установки: 2.0
Установка на трассе: True
Исходных точек: 127
Подготовленных точек: 127
```

При первом запуске загрузка данных о рельефе может занять некоторое время. Повторные обращения к той же области могут использовать кеш библиотеки.

Если API-ключ OpenTopography не указан, программа выдаст ошибку.

## 9. Принцип работы

Подготовка трассы выполняется следующим образом:

```text
Исходные координаты трассы
           |
           v
       ElevationProvider
           |
           v
       Высоты точек

Исходные координаты трассы
           |
           v
      CoordinateConverter
           |
           v
       Координаты X, Y

Координаты X, Y + высоты
           |
           v
          Point
           |
           v
          Track
```

Объект `Track` хранит подготовленные точки трассы и её параметры.

В дальнейшем эти данные будут использоваться математической моделью снежных пушек и алгоритмом оптимизации.

## 11. Особенности проекта

SmartSnow не является системой управления реальными снежными пушками.

Это исследовательская программа для математического моделирования, оценки покрытия лыжной трассы и поиска эффективных вариантов размещения оборудования.

Результаты моделирования зависят от точности исходных географических данных, характеристик снежных пушек и принятых допущений.
